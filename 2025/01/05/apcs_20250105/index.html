題解

P1 - 等紅綠燈

link >> https://zerojudge.tw/ShowProblem?problemid=q181

題目敘述

操場起跑線上有一個紅綠燈，綠燈為aaa秒，紅燈為bbb秒，依照綠燈紅燈的順序循環。 有nnn個小朋友，從操場的起跑線騎腳踏車一起起跑，他們分別騎完一圈的時間為t1,t2,t3,...tnt_1, t_2, t_3, ... t_nt1​,t2​,t3​,...tn​。若騎到終點時為紅燈，需要等待紅燈結束變為綠燈才可以停止騎車。 求出這nnn個小朋友共需要等待幾秒的紅燈秒數。

想法

cycle_time 決定tit_iti​完成一圈後所剩餘的循環秒數，如果不小於aaa，代表當前為紅燈，就要將剩餘的紅燈等待時間加入到 total_time 中。

解答

P2 - 字串操作

link >> https://zerojudge.tw/ShowProblem?problemid=q182

題目敘述

給一個字串SSS(長度為偶數)，有三種字串操作，分別如下

    1. 兩兩交換：將字串內相鄰兩個字元交換，例如字串 “apcsntnu” 先分組成 (ap)(cs)(nt)(nu)，將會交換為 (pa)(sc)(tn)(un)，即得到 “pasctnun”。
    1. 兩兩排序：將字串內相鄰兩個字元按照字典序排序，字元的字典序為 a < b < … < z，例如字串 “family” 先分組成 (fa)(mi)(ly)，將會交換成 (af)(im)(ly)，即得到 “afimly”。
    1. 完美重排：假設字串長度為nnn，將字串內的字元編號為0,1,2,...,n−10,1,2,...,n-10,1,2,...,n−1，將字串分成兩半為0,1,2,...,n2−10,1,2,...,\frac{n}{2}-10,1,2,...,2n​−1和n2,n2+1,...,n−1\frac{n}{2}, \frac{n}{2}+1, ..., n-12n​,2n​+1,...,n−1，並且組合成0,n2,1,n2+1,...,n2−1,n−10,\frac{n}{2},1,\frac{n}{2}+1,...,\frac{n}{2}-1,n-10,2n​,1,2n​+1,...,2n​−1,n−1。例如"apcsntnu"拆成"apcs"和"ntnu"，然後交錯成 “anptcnsu”。

想法

定義三個函式，代表三個操作，只要按照題目要求操作就好，沒有什麼好想的。

解答

P3 - 重組問題

link >> https://zerojudge.tw/ShowProblem?problemid=q183
從這一題開始後，都是我後來回來看的想法以及題解。

題目敘述

對於一個長度為nnn的陣列a1,a2,a3,...,ana_1,a_2,a_3,...,a_na1​,a2​,a3​,...,an​，已知a1=0a_1=0a1​=0，定義Δ\DeltaΔ為陣列中任兩個數字的絕對值差所組成的一群數字。給定Δ\DeltaΔ的內容，輸出可以生成該Δ\DeltaΔ的最小與最大字典序陣列。

舉例來說，如果n=3n=3n=3且Δ=(3,4,7)\Delta=(3,4,7)Δ=(3,4,7)，距離最大的是777，因為最大距離必定是在最小與最大兩數之間，我們可以推論原序列的最大的數字是777。接著，目前已知原序列有(0,7)(0,7)(0,7)，而距離序列扣除777之後剩下(3,4)(3,4)(3,4)，我們要決定中間點的位置。此時最大的距離是444，這個距離必然是該未知點與「最小的0」或與「最大的7」之間的距離，所以這個點可能是444或333，在檢驗距離序列後，發現兩者皆可能，所以原序列可能是(0,3,7)(0,3,7)(0,3,7)或(0,4,7)(0,4,7)(0,4,7)，其中字典序最小的是(0,3,7)(0,3,7)(0,3,7)，最大的是(0,4,7)(0,4,7)(0,4,7)。

想法

因為那時候的我演算法基礎不佳，我在紙上一直寫，寫到最後也不太知道怎麼辦，最後就只能交出白卷了。

題目一直強調「距離」這個概念，我們可以把一個序列畫在數線上，分析他們兩兩之間的距離，距離所組成的序列就叫做Δ\DeltaΔ。原序列中，最大的元素ana_nan​就是max(Δ)−a1=max(Δ)max(\Delta)-a_1=max(\Delta)max(Δ)−a1​=max(Δ)，而按照Δ\DeltaΔ找到字典序小的方法就是依序找到數字最小的元素就好；反過來說，要找到字典序最大的方法就是找到數字元素最大的就好。

在字典序最小的序列中，我可以知道ana_nan​一定是max(Δ)max(\Delta)max(Δ)，而且為了使a1a_1a1​最小，我一定要將剩下Δ\DeltaΔ中最大的元素作為∣an−a1∣|a_n-a_1|∣an​−a1​∣，就可以確保a1a_1a1​最小；而在字典序最大的序列中，一樣知道ana_nan​一定是max(Δ)max(\Delta)max(Δ)，而且為了使a1a_1a1​最大，我一定要將剩下Δ\DeltaΔ中最大的元素作為∣a1−a0∣|a_1-a_0|∣a1​−a0​∣，就可以確保a1a_1a1​最大。而往後我們就依照這個邏輯枚舉，就可以找出原序列了！
